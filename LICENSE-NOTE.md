# Licensing

No licence is set. Until you add one, default copyright applies and nobody may
reuse the code. Two common choices:

- **MIT** — permissive, anyone may use it with attribution. Usual pick for a
  portfolio project.
- **CC BY 4.0** for the dataset, since a software licence fits code better
  than photographs and tables.

GitHub can add either for you: **Add file → Create new file → name it
`LICENSE`**, then use the "Choose a license template" button.

The photographs in `data/frames/` were taken at a hostel plate-return counter.
Frames containing a face or a person were removed automatically, but the filter
is not perfect — look through them yourself before making this repository
public.
